# คู่มือการใช้งานระบบ SV.GOLF One Stop Service

คู่มือฉบับนี้จัดทำขึ้นเพื่อแนะนำวิธีการใช้งานระบบ SV.GOLF One Stop Service ซึ่งประกอบด้วยระบบหลักและระบบย่อยตามบทบาทผู้ใช้ต่าง ๆ (ไม่รวมผู้ดูแลระบบ) เพื่อประสิทธิภาพและเสถียรภาพในการดำเนินงานระดับสถานศึกษา เครือข่าย และเขตพื้นที่

---

## 1. Dashboard ระบบ (Main System Navigation)
ระบบศูนย์กลางที่รวบรวมบริการดิจิทัลทั้งหมดไว้ในหน้าเดียว เพื่อความสะดวกในการเข้าถึง

🎥 **วิดีโอสาธิตการใช้งาน:** [แนะนำระบบ (Main Dashboard)](https://youtu.be/_B-V_ftcIkY?si=xo4EtlYktZI-Bzss)

### 1.1 การเข้าสู่ระบบและหน้าต้อนรับ (Splash Screen)
- เมื่อเข้าสู่ลิงก์ของระบบ จะพบกับหน้าต้อนรับ (Welcome Page)
- คลิกที่ปุ่ม **"เข้าสู่ระบบ / Enter Dashboard"** เพื่อเข้าสู่หน้าเมนูหลัก

### 1.2 การใช้งานหน้าเมนูหลัก (Dashboard)
- หน้า Dashboard จะแสดงเมนูของระบบย่อยต่างๆ ในรูปแบบการ์ดที่สวยงาม
- **การเข้าใช้งานระบบย่อย:** คลิกที่ปุ่ม **"เข้าใช้งานระบบ"** บนการ์ดที่ต้องการ (เช่น ระบบนิเทศติดตาม, RT Toolkit, Pre-RT Online NAN1)
- **ระบบสถานะ:** หากการ์ดแสดงสถานะ "ปิดระบบ" ผู้ใช้ทั่วไปจะไม่สามารถเข้าใช้งานได้ (สงวนไว้สำหรับผู้ดูแลระบบ)
- **การดูสถิติ:** ด้านบนของหน้าจอจะแสดงสถิติภาพรวม เช่น จำนวนผู้เข้าชมระบบ และสถิติการนิเทศโรงเรียน

## 2. ระบบ RT Toolkit (เครื่องมือสร้างใบงาน)
ระบบสำหรับคุณครูเพื่อใช้สร้างใบงานแบบฝึกทักษะการอ่านภาษาไทยโดยอัตโนมัติ

🎥 **วิดีโอสาธิตการใช้งาน:** [เครื่องมือสร้างใบงาน RT Toolkit](https://youtu.be/7cQFHrgprvM?si=JNZ1xyKxdeQJFj3x)

### 2.1 การเข้าสู่ระบบ
- เลือกเมนู **"RT Toolkit"** จากหน้า Dashboard
- กรอกข้อมูลพื้นฐาน ได้แก่ **ชื่อครูผู้สอน** และเลือก **โรงเรียน** จากเมนูดรอปดาวน์
- คลิกปุ่ม **"เข้าสู่ระบบสร้างใบงาน"**

### 2.2 การสร้างใบงาน
- เมื่อเข้าสู่ระบบ จะพบกับแผงควบคุม (Control Panel) และตัวอย่างใบงาน (Preview)
- **กำหนดรายละเอียด:** เลือกชั้นเรียน, วิชา และกรอกคำชี้แจงสำหรับใบงาน
- **เลือกคำศัพท์:** พิมพ์คำศัพท์ที่ต้องการลงในช่อง (รองรับการวางคำศัพท์ทีละหลายคำ) แล้วกดปุ่ม **"เพิ่มคำศัพท์"**
- คำศัพท์ที่เพิ่มจะแสดงในรายการด้านล่าง สามารถกดปุ่มถังขยะเพื่อลบคำที่ไม่ต้องการได้
- **การสุ่มคำศัพท์:** หากต้องการให้ระบบสุ่มคำศัพท์ให้อัตโนมัติ สามารถกดปุ่ม **"สุ่มคำศัพท์จากฐานข้อมูล"**

### 2.3 การพิมพ์และบันทึกใบงาน (PDF)
- ตรวจสอบความถูกต้องของใบงานในหน้าต่าง Preview ด้านขวา
- คลิกปุ่ม **"พิมพ์ใบงาน / Print PDF"** 
- ระบบจะสร้างไฟล์ PDF ที่มีรูปแบบสวยงาม พร้อมนำไปใช้งานได้ทันที

## 3. ระบบ Pre-RT Online NAN1
ระบบจัดสอบและประเมินผลออนไลน์ผ่านเว็บแอปพลิเคชัน โดยแบ่งการเข้าใช้งานตามบทบาท (ยกเว้นผู้ดูแลระบบ) เพื่อความปลอดภัยและประสิทธิภาพสูงสุด

🎥 **วิดีโอสาธิตการใช้งาน:** [ระบบจัดสอบและประเมินผล Pre-RT Online](https://youtu.be/t-z9FtQS3ko?si=LwLBo-TU6izK3an8)

### 3.1 วิธีการเข้าใช้งานระบบ (Method of Access)
- **ทางเข้าสู่ระบบ:** ในหน้าจอ Dashboard หลักของระบบ ให้เลือกการ์ดเมนู **"Pre-RT Online NAN1"**
- **สิทธิ์การเข้าใช้งาน:** สามารถลงชื่อเข้าใช้งานแยกตามกลุ่มบทบาทด้วยบัญชีผู้ใช้เฉพาะตัว (สำหรับคุณครู/ผู้บริหาร) หรือดำเนินการสมัครสอบ (สำหรับนักเรียน)

### 3.2 โหมดนักเรียน (Student Mode)
> **หมายเหตุ:** ครูเป็นผู้สมัครสมาชิกและตั้งรหัสผ่านให้นักเรียนล่วงหน้า นักเรียนเพียงนำ Username และ Password ที่ครูแจกให้มากรอกเพื่อเข้าสอบ
- **เข้าห้องสอบ:** กรอก **ชื่อผู้ใช้ (Username)** และ **รหัสผ่าน (Password)** ที่คุณครูแจกให้ แล้วกดปุ่ม **"เข้าสู่ห้องสอบ"**
- **เลือกชุดข้อสอบ:** เลือกชุดที่ครูเปิดให้ทำในวันนั้น
- **ทำข้อสอบ (ข้อ 1-10):** อ่านโจทย์แล้วเลือกคำตอบที่ถูกต้องทางด้านขวาของหน้าจอ
- **ส่งคำตอบ:** เมื่อทำครบแล้ว กดปุ่ม **"ส่งคำตอบ ✅"** ระบบบันทึกคะแนนให้อัตโนมัติ

### 3.3 โหมดคุณครูผู้สอน (Teacher Mode)
- **การจัดการข้อมูลผู้เรียน (การลงทะเบียน):** 
  - ลงทะเบียนนักเรียนรายบุคคลโดยระบุห้องเรียน หรือดำเนินการอัปโหลดรายชื่อแบบกลุ่มผ่านไฟล์ **CSV**
  - ระบบจัดทำไฟล์ CSV ตัวอย่างให้ดาวน์โหลดเป็น UTF-8 BOM ทำให้เปิดเขียนและบันทึกผ่าน Microsoft Excel ใน Windows ได้โดยไม่มีปัญหาตัวอักษรไทยเพี้ยน
- **การดาวน์โหลดเอกสารจัดสอบ:** คุณครูสามารถดาวน์โหลดไฟล์ PDF **ตัวข้อสอบสำหรับนักเรียน** และ **เกณฑ์คู่มือประเมินสำหรับคุณครู** เพื่อนำมาใช้ในการสอบปากเปล่าได้ทันที
- **การประเมินการอ่านออกเสียงอัตนัย (ข้อ 11-15):** 
  - ในตารางคะแนนนักเรียนรายบุคคล คุณครูสามารถคลิกปุ่ม **"📝 ให้คะแนนอ่านรู้เรื่อง (11-15)"** หรือ **"🎤 ประเมินอ่านออกเสียง"** เพื่อให้คะแนนการอ่านออกเสียงเต็มข้อละ 2 คะแนน (0, 1, 2)
  - เมื่อบันทึกแล้วระบบจะคำนวณรวมกับคะแนนปรนัยส่วนแรกให้อัตโนมัติ
- **ระบบจัดเรียงรายชื่ออัจฉริยะ (Smart Sorting):** ตารางรายชื่อนักเรียนจะแสดงป้ายกำกับ **"ห้อง X"** สีเทาอย่างสวยงาม และทำการจัดเรียงรายชื่อโดย **เรียงตามห้องเรียนก่อน (ห้อง 1, 2, 10) จากนั้นจึงจัดเรียงตามลำดับตัวอักษรพจนานุกรมไทย ก-ฮ** เพื่อความสะดวกในการค้นหาและตรวจผลสอบ
- **การวิเคราะห์ทักษะเชิงลึก:** คุณครูสามารถกดปุ่ม **"📊 วิเคราะห์ผล"** เพื่อแสดงทักษะเรดาร์ชาร์ทวิเคราะห์จุดเด่นจุดด้อยรายบุคคล และดาวน์โหลดพิมพ์ผลสอบเฉพาะหน้านักเรียนคนนั้นๆ ได้โดยตรง

### 3.4 โหมดผู้บริหารสถานศึกษา / ศึกษานิเทศก์ (Supervisor / Principal Mode)
- **ขอบเขตของข้อมูล:** สามารถเรียกดูวิเคราะห์ผลลัพธ์ของ **ทุกโรงเรียนที่อยู่ในสังกัดกลุ่มเครือข่ายเดียวกัน** กับของตนเอง
- **การเรียกดูสารสนเทศ:** ตรวจสอบสถิติจำนวนผู้เข้าสอบ คะแนนเฉลี่ย แผนภูมิใยแมงมุมวิเคราะห์ทักษะรายด้าน และเปรียบเทียบคะแนนแต่ละโรงเรียน
- **สิทธิ์การดำเนินการสอบ:** มีสิทธิ์ในการดาวน์โหลดข้อสอบ และสามารถกดให้คะแนนช่วยเหลือหรือดำเนินการประเมินการอ่านออกเสียง (ข้อ 11-15) ของนักเรียนในเครือข่ายได้เช่นเดียวกับครูผู้สอน

### 3.5 โหมดผู้บริหารเขตพื้นที่การศึกษา (Executive Mode)
- **สถิติระดับเขตพื้นที่เป็นตัวตั้งต้น:** แสดงผลการวิเคราะห์ สถิติเชิงเปรียบเทียบ และคะแนนผลสัมฤทธิ์ของทุกโรงเรียนและทุกเครือข่ายในเขตพื้นที่ทั้งหมดทันทีหลังเข้าสู่ระบบ
- **ระบบตัวกรองกลุ่มเครือข่าย (Cluster Filter):** มีปุ่มดรอปดาวน์ด้านบนสุดเพื่ออำนวยความสะดวกในการ **เลือกแสดงผลเฉพาะกลุ่มเครือข่ายที่สนใจ** โดยระบบจะทำการอัปเดตสถิติ แผนภูมิวิเคราะห์ และตารางคะแนนแบบไดนามิก Real-time

## 4. ระบบนิเทศออนไลน์ (Classroom Observation)
ระบบสำหรับศึกษานิเทศก์และผู้บริหารเพื่อบันทึกข้อมูลการสังเกตชั้นเรียนและออกรายงานแบบมืออาชีพ

🎥 **วิดีโอสาธิตการใช้งาน:** [ระบบบันทึกผลการนิเทศออนไลน์](https://youtu.be/0yn1ZP7qkFk?si=v-IQhKu4sUjpjuZ9)

### 4.1 การเข้าสู่ระบบ
- เลือกเมนู **"ระบบนิเทศออนไลน์"** จากหน้า Dashboard
- กดปุ่ม **"เข้าสู่ระบบสำหรับศึกษานิเทศก์"** และกรอกรหัส PIN ประจำตัว

### 4.2 การบันทึกการนิเทศชั้นเรียน (3 ขั้นตอน)
- คลิกปุ่ม **"+ บันทึกการนิเทศใหม่"** บนหน้า Dashboard
- **ขั้นที่ 1: ข้อมูลทั่วไป:** กรอกข้อมูลโรงเรียน, ชื่อครูผู้สอน, รายวิชา, วันเวลาที่นิเทศ และจำนวนนักเรียน
- **ขั้นที่ 2: บันทึกพฤติกรรมการสอน:**
  - บันทึกรายละเอียดการสอนในแต่ละขั้น (ขั้นนำ, ขั้นสอน, ขั้นสรุป)
  - ประเมินรายการสังเกตชั้นเรียนทั้ง 10 รายการ โดยให้คะแนน (1-5) ตามระดับการปฏิบัติ
- **ขั้นที่ 3: สรุปและแนบรูปภาพ:**
  - กรอกจุดเด่น, จุดที่ควรพัฒนา และข้อเสนอแนะ
  - อัปโหลดรูปภาพประกอบการนิเทศ (รองรับสูงสุด 4 ภาพ)
- ตรวจสอบข้อมูลและกดปุ่ม **"บันทึกข้อมูล"**

### 4.3 การดูแดชบอร์ดสรุปผลการนิเทศ
- หน้า Dashboard จะแสดงภาพรวมการนิเทศทั้งหมด
- **กราฟแมงมุม (Radar Chart):** แสดงค่าเฉลี่ยของผลการประเมินทั้ง 10 ด้าน เพื่อให้เห็นภาพรวมของจุดแข็งและจุดอ่อน
- **รายงานสรุป:** แสดงจำนวนครั้งที่นิเทศ, จำนวนครู, จำนวนนักเรียนทั้งหมด และค่าเฉลี่ยคะแนนประเมิน

### 4.4 การพิมพ์รายงานสรุป (PDF)
- ในหน้ารายการประวัติการนิเทศ ให้คลิกปุ่ม **"ดูรายงาน"** ของรายการที่ต้องการ
- ระบบจะแสดงหน้าจอรายงานสรุปแบบละเอียด พร้อมรูปภาพประกอบ
- คลิกปุ่ม **"Print PDF"** ระบบจะสร้างเอกสารรายงานรูปแบบทางการ (A4) ที่มีการเว้นขอบ 15 มม. ทุกหน้า และมีช่องสำหรับลงนามด้านท้ายเอกสาร พร้อมพิมพ์หรือส่งเป็นไฟล์ PDF ได้ทันที

## 5. ระบบกิจกรรมประชุมออนไลน์
ระบบสำหรับลงทะเบียนและจัดการกิจกรรมประชุม สัมมนา และอบรมออนไลน์

### 5.1 การเข้าร่วมกิจกรรมประชุม
- เลือกเมนู **"ระบบประชุมออนไลน์"** จากหน้า Dashboard
- ดูรายการการประชุมที่เปิดให้ลงทะเบียน หรือกำลังดำเนินการอยู่
- กดปุ่มลิงก์เพื่อเข้าสู่ห้องประชุมออนไลน์ (เช่น Google Meet, Zoom) ตามที่กำหนดไว้

### 5.2 การลงทะเบียนและเช็คชื่อ
- กรอกข้อมูลส่วนตัวเพื่อลงทะเบียนเข้าร่วมกิจกรรมหรือเช็คชื่อเข้าห้องประชุม
- ระบบจะบันทึกเวลาและข้อมูลการเข้าร่วมของท่านโดยอัตโนมัติ

### 5.3 การรับเอกสารและวุฒิบัตร (ถ้ามี)
- หลังจบการประชุม ท่านสามารถดาวน์โหลดเอกสารประกอบการประชุมได้จากระบบ
- สำหรับกิจกรรมที่มีวุฒิบัตร สามารถทำแบบประเมินและดาวน์โหลดวุฒิบัตรอิเล็กทรอนิกส์ได้ทันที

---

> **หมายเหตุ:** หากพบปัญหาการใช้งาน หรือต้องการสอบถามข้อมูลเพิ่มเติม สามารถติดต่อผู้ดูแลระบบ (Admin) หรือกดปุ่ม **"คู่มือ"** ที่มุมขวาล่างของแต่ละหน้าจอเพื่อดูเอกสารช่วยเหลือ
